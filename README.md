# VolunteerConnect 🤝

> A comprehensive social impact, logistics, and audited aid platform simulation.

VolunteerConnect is a modern, responsive web platform featuring multi-role simulation across community, logistics, field operations, and financial aid auditing pipelines.

## 🚀 Live Demo
Once deployed via GitHub Pages, you can access the live website at:
https://wazidabdullah.github.io/VolunteerConnect/

## ✨ Features
- **10 Dedicated Simulated Roles**: Volunteers, In-Kind Goods Donors, Aid Beneficiaries, Organizers, Regional Logistics/Warehouse Managers, QC Inspectors, Fleet Coordinators, Field Directors, Aid Auditors, and Admins.
- **Self-Contained & Zero Setup**: Built entirely with HTML5, Tailwind CSS (via CDN), and Vanilla JavaScript.
- **Interactive UI**: Modal workflows, status tracking, role-based dashboards, and responsive layout.

## 💻 Local Preview
To run locally, simply open [index.html](index.html) directly in any web browser, or use a local development server:
```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve
```
